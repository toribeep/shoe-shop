# ShoeShop — система оформления заказов обуви

Учебный проект: десктопное приложение для работы с каталогом обуви и оформления заказов.

## Возможности

- просмотр каталога обуви;
- отображение информации о товарах;
- создание и редактирование товаров;
- оформление и управление заказами;
- работа с данными пользователей.

## Требования

- Python 3.13;
- PostgreSQL;
- библиотеки из файла `requirements.txt`.

## Установка и запуск

1. Клонировать репозиторий:

   `git clone <адрес репозитория>`

2. Создать виртуальное окружение:

   `python -m venv .venv`

3. Активировать окружение в Git Bash:

   `source .venv/Scripts/activate`

4. Установить зависимости:

   `pip install -r requirements.txt`

5. Создать базу данных PostgreSQL и настроить параметры подключения в `config.py`.

6. Запустить приложение:

   `python main.py`

## Структура репозитория

- `main.py` — точка входа в приложение;
- `auth_window.py` — окно авторизации;
- `database.py` — работа с базой данных;
- `models.py` — модели данных;
- `resources/` — изображения и другие ресурсы;
- `data/` — файлы с данными;
- `create_tables.sql` — скрипт создания таблиц базы данных;
- `requirements.txt` — список зависимостей.

## ER-диаграмма базы данных

ER-диаграмма базы данных проекта представлена в файле `docs/er-diagram.png`.

База данных включает следующие основные таблицы:

- **users** — хранит сведения о пользователях системы.
- **products** — содержит информацию о товарах: артикул, название, цену, категорию, скидку, количество и описание.
- **orders** — хранит сведения о заказах: номер, даты, данные клиента, пункт выдачи и статус заказа.
- **order_items** — содержит состав заказа: номер заказа, артикул товара и количество.
- **pickup_points** — хранит адреса пунктов выдачи заказов.

### Связи между таблицами

Таблица `orders` связана с `order_items` по номеру заказа. Один заказ может содержать несколько позиций.

Таблица `order_items` связана с `products` по артикулу товара. Это позволяет указать товары и их количество в заказе.

Таблица `orders` связана с `pickup_points` по адресу пункта выдачи.
